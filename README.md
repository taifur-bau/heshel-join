# রোজকার হেঁশেল · আমন্ত্রণ পাতা

রোজকার হেঁশেল অ্যাপের আমন্ত্রণ লিংক এই পাতায় খোলে। পাতা থেকে অ্যাপ খোলে, আর অ্যাপ না থাকলে ডাউনলোডের ব্যবস্থা দেখায়।
এখানে কোনো পরিবারের তথ্য বা অ্যাপের সাইনিং কী রাখা হয় না। মূল কোড প্রাইভেট রিপোজিটরিতে আছে।

- `index.html`: আমন্ত্রণ পাতা (`?t=<টোকেন>`)
- `app/rojkar-heshel.apk`: সর্বশেষ অ্যান্ড্রয়েড অ্যাপ
